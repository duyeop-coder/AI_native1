# 입력 템플릿 (복사해서 그대로 사용)

아래 블록 전체를 복사해 `( )` 부분만 채워 유저 프롬프트로 보냅니다.
`[관련 규정]`이 비어 있으면 어시스턴트는 답변을 만들지 않고 규정을 요청합니다.

```
[문의 원문]
(교육생이 보낸 문의를 그대로 붙여넣기)

[교육생 정보]
(이름/기수, 이번 달 교육일수, 출석·지각·결석·병가 일수 등 - 모르면 "미상")

[관련 규정]
(운영규정 해당 조항 원문을 그대로 붙여넣기)

[답변 채널/톤]
(예: 이메일 / 정중하고 간결하게)
```

## 작성 예시

```
[문의 원문]
이번 달에 지각을 4번 했는데 장려금 받을 수 있나요?

[교육생 정보]
김OO / 3기, 이번 달 교육일 20일, 결석 2일, 지각 4회, 병가 0일

[관련 규정]
제5조(출석) ① 월 출석률 80% 이상이면 ... ② 지각 또는 조퇴 3회는 결석 1일로 처리한다.
제7조(훈련장려금) ① 월 출석률 80% 이상인 교육생에게 월 30만 원을 지급한다. ...

[답변 채널/톤]
이메일 / 정중하고 간결하게
```
