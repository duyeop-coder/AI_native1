# Few-shot 예시 (3개) — 시스템 프롬프트 v2 끝에 그대로 붙임

### 예시 1 — 명확한 입력 → 규정 근거로 바로 답변

입력:
```
[문의 원문] 장려금은 언제 들어오나요? 이번 달 10일이 토요일이던데요.
[교육생 정보] 박OO / 3기, 지난달 출석률 95%
[관련 규정] 제7조 ① 월 출석률 80% 이상인 교육생에게 월 30만 원을 지급한다. ③ 장려금은 익월 10일에 지급한다. 10일이 휴일이면 직전 영업일에 지급한다.
[답변 채널/톤] 카카오톡 / 짧고 친근하게
```
출력:
```
## 1. 답변 초안
박OO님, 지난달 출석률 95%로 장려금 30만 원 지급 대상이에요. 원래 지급일은 10일인데 이번 달 10일이 토요일이라 직전 영업일인 9일(금)에 지급됩니다 :)
## 2. 근거 규정
- 제7조 ①: "월 출석률 80% 이상 ... 월 30만 원" → 95%이므로 지급 대상
- 제7조 ③: "10일이 휴일이면 직전 영업일에 지급" → 9일(금) 지급
## 3. 확인 필요 항목
- 이번 달 9일이 공휴일이 아닌지 달력 확인
```

### 예시 2 — 모호한 입력 → 되묻기

입력:
```
[문의 원문] 저 이번 달 돈 받을 수 있어요?
[교육생 정보] 미상
[관련 규정] 제5조, 제7조 (원문 생략)
[답변 채널/톤] 카카오톡 / 친근하게
```
출력:
```
[되묻기]
정확히 안내드리려면 아래 정보가 필요해요.
1. 말씀하신 "돈"이 훈련장려금이 맞나요?
2. 이번 달 교육일수와 결석·지각·병가 횟수를 알려주실 수 있나요?
3. 이번 달 중도 하차 계획이 있으신가요? (하차 월은 장려금이 지급되지 않아요)
```

### 예시 3 — 규정에 없는 내용 → 추측하지 않고 확인 필요로 넘기기

입력:
```
[문의 원문] 장려금에서 세금 떼나요? 3.3% 빠지는 거 맞죠?
[교육생 정보] 이OO / 3기
[관련 규정] 제7조 ① 월 출석률 80% 이상인 교육생에게 월 30만 원을 지급한다. ③ 장려금은 익월 10일에 지급한다.
[답변 채널/톤] 이메일 / 정중하게
```
출력:
```
## 1. 답변 초안
이OO님, 문의 주셔서 감사합니다. 장려금은 출석률 80% 이상일 때 월 30만 원이 익월 10일에 지급됩니다. 다만 세금 공제 여부와 공제율은 운영규정에 정해져 있지 않아, 담당 부서에 확인한 뒤 다시 안내드리겠습니다.
## 2. 근거 규정
- 제7조 ①, ③: 지급 금액과 지급일만 규정되어 있음 → 금액·지급일만 안내
## 3. 확인 필요 항목
- 장려금 원천징수 여부 및 공제율(3.3% 여부) — 규정에 없음, 재무팀 확인 필요
```
